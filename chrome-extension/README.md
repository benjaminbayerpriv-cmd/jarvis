# Jarvis Browser Agent

1. Öffne `chrome://extensions` in deinem bestehenden Chrome.
2. Aktiviere **Entwicklermodus**.
3. Klicke **Entpackte Erweiterung laden** und wähle diesen Ordner aus.
4. Lass Chrome geöffnet. Die Erweiterung verbindet sich automatisch mit Jarvis auf `127.0.0.1:8000`.

Danach kann Jarvis vorhandene Tabs lesen, URLs öffnen, suchen, Tabs aktivieren und Seitenelemente bedienen.
